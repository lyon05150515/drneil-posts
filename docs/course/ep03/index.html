延伸閱讀

瘦子也會脂肪肝，關鍵不在胖

2025-05-13

脂肪肝不只胖子會得，台灣脂肪肝患者約有三分之一 BMI 正常，成因常與精製糖和澱粉有關，可靠飲食、重訓與睡眠改善。

果糖對身體造成的影響

2023-10-12

果糖結構類似酒精僅由肝臟代謝，攝取過多易導致非酒精性脂肪肝、三酸甘油脂升高與尿酸增加，戒掉水果和含蔗糖飲料可大幅改善。

吃水果的盲區，不只是你想的那樣

2026-04-19

血糖機測葡萄糖不測果糖，水果同含三種糖並經蔗糖分解，果糖進肝臟繞過血糖控制轉化為脂肪和尿酸，血糖讀數只揭示代謝故事的一部分。

為什麼吃油不會變脂肪，吃糖反而最危險

2026-04-12

血液三酸甘油酯的主要來源是肝臟用糖製造的，而非直接來自食物脂肪，吃糖越多製造越多。

脂肪肝裡，脂肪對肝細胞做了什麼

2026-06-29

脂肪肝是肝細胞內游離脂肪酸等造成內質網壓力、粒線體損傷、細胞死亡，進而引發發炎與纖維化的連鎖傷害過程。

消脂肪肝，運動強度沒你想的那麼重要

2026-06-28

消除脂肪肝的運動強度沒有想像中重要，中等強度有氧運動足以有效改善肝臟脂肪，比高強度訓練更可持續。
